### Завдання 1. «Динамічний одновимірний масив»

### Завдання 2. «Динамічний двовимірний масив»
* **Умова:** Підрахувати кількість додатних елементів у даному двовимірному масиві.
* **Реалізація:** Створено динамічну матрицю розміром 3х4, яка заповнюється випадковими числами, після чого виконується пошук та підрахунок додатних елементів із подальшим коректним звільненням пам'яті.

## 📌 Висновок
Під час виконання лабораторної роботи було успішно закріплено навички роботи з динамічною пам'яттю в C++. Порівняно ручне керування пам'яттю за допомогою операторів `new`/`delete` та безпечний підхід із використанням контейнера `std::vector`. Набуто досвіду написання алгоритмів для обробки числових даних у масивах і матрицях.
